# Art inbox

Drop new visual assets here for review and integration.

Files placed in this folder are ignored by Git by default. During integration, assets will be:

1. checked for transparency, dimensions, cropping, and alignment;
2. renamed with a clear project-friendly filename;
3. copied into the appropriate game asset folder when approved for use;
4. wired into the Canvas renderer and tested at mobile and desktop sizes.

Do not commit personal reference originals. Explicitly approved public copies may be added to game assets after removing camera metadata; keep the originals here and Git-ignored.
